
# AttendEase

AttendEase is a desktop application for managing student attendance, built with Java Swing and an SQLite database.

## Features

- Add, edit, and delete student records
- Record attendance status and check-in/check-out times
- View attendance for the current date
- Calculate a student's attendance percentage

## Requirements

- Java Development Kit (JDK) 11 or later
- Internet access the first time you build the project (for Gradle dependencies)
